Создайте RESTful API с использованием Django Rest Framework, которое предоставляет доступ к данным вашего приложения. API должно поддерживать операции CRUD (создание, чтение, обновление, удаление).  API должно быть готово к интеграции с фронтендом (React/Vue.js) или мобильными приложениями.

Требования:

- БД должна содержать не менее 3 связанных таблиц.
- В API должна быть реализована обязательная аутентификация через JWT-токены. 
- Должны быть ресурсы, доступные без авторизации, но их меньшенство.
- Должна быть реализована пагинация для всех списковых представлений (List endpoints). 
- Документация по использованию API должна быть оформлена с помощью Swagger. 
- В интерфейсе Swagger должна быть кнопка "Authorize" для ввода JWT-токена и отправки авторизованных запросов прямо из браузера.
- Приложение должно работать через docker.
- Предпочтение по бд: PostgreSQL.
- Используемые фреймворки: DRF, DRF-simplejwt.

Вариант: API для биржи услуг.
